📋 المتطلبات:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
□ Windows 11
□ XAMPP (Apache + MySQL + PHP)
□ متصفح Chrome أو Edge

🔧 خطوات التثبيت:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

الخطوة 1: تثبيت XAMPP
──────────────────────────────────────────────────────────────
1. افتح المتصفح
2. ادخل على: https://www.apachefriends.org
3. حمّل XAMPP for Windows
4. ثبّته في المسار الافتراضي: C:\xampp

الخطوة 2: نسخ ملفات التطبيق
──────────────────────────────────────────────────────────────
1. افتح مجلد: C:\xampp\htdocs
2. أنشئ مجلد جديد: aljawzi
3. انسخ جميع الملفات إلى هذا المجلد:
   - config.php
   - database_setup.sql
   - api/ (مجلد)
   - admin/ (مجلد)
   - .htaccess

الخطوة 3: إنشاء قاعدة البيانات
──────────────────────────────────────────────────────────────
1. افتح XAMPP Control Panel
2. اضغط "Start" بجانب Apache و MySQL
3. افتح المتصفح وادخل: http://localhost/phpmyadmin
4. اضغط "New" لإنشاء قاعدة بيانات جديدة
5. اسم القاعدة: aljawzi_db
6. اضغط "Create"
7. اضغط على القاعدة الجديدة
8. اذهب إلى تبويب "SQL"
9. افتح ملف database_setup.sql وانسخ محتواه
10. الصقه في phpMyAdmin واضغط "Go"

الخطوة 4: اختبار الاتصال
──────────────────────────────────────────────────────────────
1. افتح المتصفح
2. ادخل: http://localhost/aljawzi/api/verify_login.php
3. يجب أن ترى رسالة JSON

الخطوة 5: فتح لوحة التحكم
──────────────────────────────────────────────────────────────
1. ادخل: http://localhost/aljawzi/admin/
2. ستظهر لوحة التحكم الرئيسية

📱 ربط التطبيق بالسيرفر:
──────────────────────────────────────────────────────────────
1. افتح ملف التطبيق (HTML)
2. ابحث عن: verifyWithServer
3. غيّر الرابط إلى:
   http://YOUR_COMPUTER_IP/aljawzi/api/verify_login.php

لمعرفة IP الكمبيوتر:
- افتح Command Prompt
- اكتب: ipconfig
- ابحث عن "IPv4 Address"

🔒 أمان إضافي:
──────────────────────────────────────────────────────────────
□ غيّر كلمة سر root في MySQL
□ استخدم HTTPS (SSL Certificate)
□ قم بعمل نسخ احتياطي يومي

📞 الدعم الفني:
──────────────────────────────────────────────────────────────
في حالة أي مشكلة، راجع:
- سجلات الأخطاء: C:\xampp\apache\logs\error.log
- سجلات MySQL: C:\xampp\mysql\data\mysql_error.log
